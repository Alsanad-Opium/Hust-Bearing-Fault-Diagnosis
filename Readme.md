# HUST Bearing Fault Diagnosis

Machine-learning fault diagnosis from vibration signals using the HUST Bearing Dataset.

**Status:** work in progress.

## Data
Download the dataset (Version 3) from Mendeley Data:
https://data.mendeley.com/datasets/cbv7jyx4p9/3
Place the `.mat` files in `data/raw/HUST bearing dataset/`.

Dataset: Hong & Thuan (2023), CC BY 4.0.
Paper: Thuan & Hong (2023), BMC Research Notes 16, 138. https://doi.org/10.1186/s13104-023-06400-4
